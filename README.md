# Viñedos El Sueño — Landing Page

Landing page ultra premium para **Viñedos El Sueño** (Ezequiel Montes, Querétaro) — el único viñedo que abre de día y de noche.

## Stack
- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4
- Deploy: Vercel

## Desarrollo
```bash
npm install
npm run dev
```

## Estructura
- `app/page.tsx` — landing completa (hero, experiencias, vinos, vendimia, visita)
- `lib/data.ts` — datos de la marca: vinos, precios, catas, horarios, contacto
- `components/` — Nav y animaciones de scroll (Reveal)
